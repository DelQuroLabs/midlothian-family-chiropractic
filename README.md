# Midlothian Family Chiropractic website preview

Public design preview prepared by DelQuro Labs. Published with GitHub Pages.

Preview: https://mfcc.delqurolabs.dev/

This repository contains the public static website export. Internal build files and QA evidence are maintained separately. Search indexing is enabled by user request on October 16, 2026. This remains a website concept; the clinic domain has not been changed. The DelQuro Labs watermark is disabled at the user's request.

Telephone scheduling and downloadable blank forms work without a backend. No completed patient forms or other patient data are collected by this site.
